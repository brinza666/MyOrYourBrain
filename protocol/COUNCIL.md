# Council protocol

Use the council for uncertain material decisions, not deterministic formatting or every note.

1. **Positive look:** smallest viable approach, evidence, tests, benefit, assumptions.
2. **Negative look:** independent failure hypotheses, regressions, privacy/security risks, cost, simpler alternatives.
3. **Evaluation look:** map claims to evidence/criteria, reconcile disagreement, identify gaps; do not silently invent an unreviewed third solution.
4. **Chief inspector:** strongest locally validated configured model applies explicit criteria; it cannot override deterministic or human gates.

Outputs are structured records. Roles propose but never execute actions. Different prompts to one model are correlated perspectives, not independent validation.

Readiness uses verified evidence quality, claim/criterion coverage, valid references, contradiction clearance, deterministic gates, hashes, and diversity penalties. Role self-confidence is excluded. Thresholds are `0.85` low, `0.90` medium, `0.95` high. A hard gate defeats any score.

High-risk outcomes pause for separate approval. Promotion of every risk level is explicit and bound to the stored run hash.
